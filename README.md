# StockPulse

A lightweight stock analysis dashboard for tracking daily market movers and mapping price moves to likely news and catalyst themes.

## What this app does

- Surfaces the biggest daily gainers and losers
- Shows a quick summary of why the move likely happened
- Links each stock to relevant market/news catalysts
- Lets you search for a symbol and review a focused snapshot

## How to run

Open `index.html` in a browser.

## Project objective

This app is designed to support daily stock analysis with a focus on:

- identifying unusually large moves up or down
- connecting those moves to news, earnings, macro themes, and company events
- helping users analyze the reasons behind price action

## Planned enhancements

- real market data integration
- sentiment scoring from news headlines
- watchlist and saved analyses
- charting and historical comparison
- optional backend API for persistence

## Notes

This initial version is a front-end prototype intended to demonstrate the core workflow for a daily stock analysis dashboard.
